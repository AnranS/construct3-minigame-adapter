# Image rendering sample

`render-test.png` is the original image generated for this demo using the built-in `image_gen` tool on 2026-09-21. It is a 1254 × 1254 RGB PNG. It is sample game artwork, not a screenshot of a running platform or an official WeChat/TikTok asset.

The Construct project includes it as a project file. The image-rendering demo loads that file and displays it through a Construct Sprite. A copy is used as sample artwork on the documentation homepage.

## Generation prompt

Use case: stylized-concept. Asset type: a single square 1024 x 1024 PNG game illustration to exercise real image loading and sprite rendering in a Construct 3 mini-game demo, also suitable as an honest sample artwork on a developer documentation site. Primary request: create a polished playful small floating game island with a tiny teal robot explorer in the center, a vivid green grassy platform with a short stepped path and a few simple chunky trees, clear readable forms even at small size. Style: carefully art-directed low-poly 3D toy diorama with softly shaded matte materials and crisp silhouettes. Composition: complete island visible with generous clean margin on every side; centered balanced composition, no objects cropped. Backdrop: solid very pale neutral gray, no transparent checkerboard. Colors: saturated WeChat-inspired leaf green, TikTok-inspired cyan with a few warm red accents, charcoal robot details, subtle natural shadows. Lighting: soft studio daylight, cheerful but sophisticated. Constraints: no text, no letters, no logos, no UI, no watermark, no mock device frame. Return one finished image.

The tool returned 1254 × 1254 pixels; the original output is kept without resampling.
