# 文档站设计基线

用途：帮助 Construct 用户完成插件安装、HTML5 转换、小游戏 IDE 调试和原生 API 接入。参考 Godot Mini Game 的首页 / 导出流程 / API 文档信息结构，保持本项目能力和验证范围准确。

- 方向：白底、深蓝文字、绿色强调，内容型技术文档；首页展示真实导出链路，文档使用左导航、正文、页内目录。
- 字体：系统中文无衬线；代码使用系统等宽字体。正文 16px / 1.8，正文宽度最多 820px。
- 颜色、间距、圆角、宽度集中在 `assets/site.css` 的语义变量。对比满足正文 4.5:1；链接有下划线或状态标识。
- 导航：当前页 `aria-current`；移动端导航按钮有展开状态，Escape / 外部点击关闭并在适当情况下恢复焦点。页面跳转保留原生浏览器行为。
- API 目录：静态完整表格，在浏览器本地按名称、分类、平台和调用类型筛选；空结果明确提示，有重置入口，结果数量为 live region。筛选不调用原生 API。
- 代码：可复制，成功 / 失败都有文字反馈；横向滚动限制在代码区域。没有脚本时正文和 API 表格仍可阅读。
- 页面：小于 1100px 隐藏右侧目录，小于 800px 折叠主导航与文档侧栏；最小测试宽度 390px。保持键盘焦点可见，尊重 reduced-motion。
- 不使用伪造编辑器截图、虚构按钮或全平台已验证宣传；实际下载链接指向构建产物，验证状态写明范围。

验收：首页主操作、指南链接、API 搜索与组合筛选 / 空结果 / 重置、代码复制、移动导航、深层页面刷新；无页面级横向溢出，站内链接和资源全部存在。
