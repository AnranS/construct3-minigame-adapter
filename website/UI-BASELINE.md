# 文档站设计基线

用途：帮助 Construct 用户完成插件安装、HTML5 转换、小游戏 IDE 调试和原生 API 接入。保留当前信息结构、链接、下载及可核验的验证边界。

## 2026-09-21 轻量审计与设计判断

这是面向 Construct 开发者的文档站视觉更新。原站使用白底、深蓝灰文字、暗绿色强调、10px 圆角和系统字体；已有首页、六个文档路由、完整 API 筛选、下载、代码复制与移动导航。信息结构健全，无需引入框架或设计系统包。

保留站点名称和图标、主导航标签、页面 slug、现有标题锚点、API 筛选字段、真实截图、技术文案与社区项目声明。首页原有重复英文眉题、等宽三列和拟窗口流程图弱化了内容重点，本轮替换成简洁图文首屏、按平台的目录入口、真实编辑器截图和有层次的功能分组。SEO 标题、描述、canonical、sitemap 保持不变；没有外部字体、统计或运行时请求。

设计判断：浅色技术文档，微信绿色主操作，TikTok 黑、青、红限定用于平台识别。`DESIGN_VARIANCE: 5`、`MOTION_INTENSITY: 2`、`VISUAL_DENSITY: 4`。保留阅读优先的静态体验，仅为交互反馈增加 hover / active；不添加滚动动画。首页应用 design-taste-frontend 重设计原则，密集 API 表格保持现有功能组件，不套用营销页的删减规则。

## 视觉规则

- 主题：按用户要求固定亮色，`color-scheme: light`。浅中性色贯穿所有区块；代码区域也保持浅色，无暗色章节切换。
- 品牌：微信绿 `#07c160` 用于平台标识，主要操作及文字链接使用满足对比度的深绿 `#087b3e`。TikTok 黑 `#161823`、青 `#25f4ee`、红 `#fe2c55` 只用于 TikTok 平台入口和 API 契约栏；亮青与红不承担小号正文。用户明确指定多平台品牌色，覆盖 skill 默认单强调色限制。
- 字体：沿用本地系统中文无衬线，去掉未实际加载的 Inter 名称；代码使用系统等宽字体。正文 16px / 1.75，文档正文最多 820px。
- 形状：内容面板 12px，首屏媒体 16px，按钮和输入框 7px，小型代码标签 4px。变量集中在 `assets/site.css`。
- 图片：首屏使用实际图片渲染示例素材 `assets/render-test.png`，保留原始 1254px 正方形图像、不裁切，明确标记不是平台运行截图；插件区使用真实 Construct 配置截图。图片设置固定尺寸或比例避免布局跳动；首屏优先加载，其余延迟加载。
- 布局：桌面导航 72px 且单行；首页左右图文、平台导航横排、文档左导航/正文/页内目录。800px 以下采用单列与折叠菜单，API 表格只在自身容器内横向滚动。
- 层级：常规内容 0、粘性导航 20、跳转正文链接 30；避免额外浮层。

## 交互与可访问性

- 导航当前页保留 `aria-current`。移动菜单保留展开状态、Escape / 外部点击关闭和焦点恢复；原生链接可无脚本使用。
- API 表格保留完整静态内容，浏览器本地按名称、分类、平台和调用类型筛选；支持首页平台入口的查询参数。空结果有解释和重置，结果计数为 live region；筛选不调用原生 API。
- 代码复制保留成功/失败反馈；代码横向滚动限制在内容区域。无 JavaScript 时文档与目录仍可阅读。
- 保留跳转正文、键盘焦点、图片描述、原生 details 行为与 reduced-motion。文字/按钮对比目标为 WCAG AA；禁用以亮青/红作小号文字的配色。
- 没有伪造编辑器截图、平台认证或全平台验证宣传；目录数量由源码生成，首页不再把历史测试数展示为当前回归状态。

## 交付检查

运行 `npm run docs:build` 与 `npm run docs:check` 验证路由、资源、下载和 API 目录。浏览器复核首页主操作、平台链接的初始筛选、组合筛选/空结果/重置、代码复制、移动导航、深层页面刷新、390px 无页面级横向溢出。静态检查不能代替实际浏览器截图与交互检查。
