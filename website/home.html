安装插件后，会新增一个小游戏导出选项吗？

当前不会。MiniGameBridge 提供 Construct 内的平台调用接口；先导出 HTML5，再由独立 CLI 转换成微信、抖音或 TikTok 原生小游戏工程。

可以直接运行任意 H5 或第三方 JS SDK 吗？

不能保证。小游戏并非完整浏览器，本项目仅实现需要的 DOM、存储、网络和音频兼容。依赖页面布局、远程脚本或完整浏览器环境的 SDK 需要逐项适配。

目录中的 API 都经过真实设备测试了吗？

没有。当前目录有 {{API_COUNT}} 个唯一名称：微信 {{WECHAT_COUNT}}、抖音 {{DOUYIN_COUNT}}、TikTok {{TIKTOK_COUNT}}。历史微信 IDE 基线为 133 / 171 个方法可用、17 项自检通过；这个历史结果不证明新增接口和 TikTok 已通过实测。

TikTok 支付回调可以直接发货吗？

不可以。客户端回调只用于结束面板流程；服务端应验证 Webhook、核对订单并幂等发货，游戏向自己的后端查询最终状态。查看 IAP 接入指南 →

公开仓库包含 Construct 引擎吗？

仓库提供适配源码、插件和 .c3p 示例。请用自己的 Construct 编辑器导出 HTML5，再执行转换。Construct 引擎和 SDK 的适用条款属于相应权利方。
