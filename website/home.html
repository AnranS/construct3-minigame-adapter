FAQ

开始之前，你可能想知道。

安装插件后，会新增一个小游戏导出选项吗？

当前不会。MiniGameBridge 提供 Construct 内的平台调用接口；先导出 HTML5，再由独立 CLI 转换成微信或抖音小游戏工程。

可以直接运行任意 H5 或第三方 JS SDK 吗？

不能保证。小游戏并非完整浏览器，本项目仅实现需要的 DOM、存储、网络和音频兼容。依赖页面布局、远程脚本或完整浏览器环境的 SDK 需要逐项适配。

171 个 API 都经过真实设备测试了吗？

没有。171 是显式目录中的唯一 API 名称，微信 142、抖音 140。本机微信 IDE 检测到 133 个方法可用，17 项自检通过；方法存在不等于业务调用或真机验收通过。

公开仓库包含 Construct 引擎吗？

仓库提供适配源码、插件和 .c3p 示例。请用自己的 Construct 编辑器导出 HTML5，再执行转换。Construct 引擎和 SDK 的适用条款属于相应权利方。
