## 当前兼容边界

| 能力 | 当前实现与限制 |
| --- | --- |
| DOM / CSS | 只提供引擎启动和资源加载所需的有限接口，不实现完整浏览器布局、表单或任意 HTML 插件 |
| 渲染 | 使用宿主 Canvas / WebGL；本轮验证真实 Text 页面，其他插件、特效、着色器和性能需逐项目测试；未实现 WebGPU |
| Worker | 内部任务采用同线程异步兼容实现，无多线程加速、隔离或 transferable 分离语义 |
| 脚本 | 打包本地代码，拒绝远程可执行脚本、import map 和一般内联脚本 |
| 存储 | localStorage 与已识别的 runtime.storage 路径连接真实平台存储；不模拟完整 IndexedDB |
| fetch / XHR | 支持包内文件、data URL、原生 request；不提供响应流、同步 XHR、完整 cookie / credentials 管理 |
| WebSocket | 通过真实 SocketTask 桥接，保留连接与关闭状态；外部服务、域名、TLS、子协议仍需实际验证 |
| 音频 | 原生 InnerAudioContext 桥接；Web Audio 仅在宿主实际提供对应入口时暴露，完整效果链与解码路径有边界 |
| WASM | 使用真实宿主能力；微信仅接受包内路径或与已登记包内文件完全匹配的字节 |
| 平台业务 | 参数、权限、账号后端、广告位、开放数据域与平台设置由项目提供；当前新增的支付入口只处理客户端调用，最终订单与发货由服务端确认 |

各接口名称和调用种类见[API 目录](../api/)。

## 构建报告如何理解

转换器生成的 `BUILD-REPORT.json` 包含静态发现、入口和补丁记录，当前保留以下状态：

```json
{
  "validation": "build-only-not-device-verified",
  "deviceVerified": false,
  "workerExecution": "same-thread-asynchronous"
}
```

这是构建工具的状态声明，不覆盖本页单独记录的 IDE 实测证据。自己的项目完成真机验证后，应保存设备、版本、日志和复现步骤，不通过修改这一字段代替测试。开始接入请查看[快速开始](../guide/)。
